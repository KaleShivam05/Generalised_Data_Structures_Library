# 📚 Generalised Data Structures Library – C++ Project

A reusable and generic implementation of common data structures using C++ templates.

---

## 📌 Description

This project provides a library of generalized data structures such as:

- Linked List  
- Stack  
- Queue  
- Binary Search Tree  

All data structures are implemented using templates, allowing them to work with any data type.

---

## 🛠 Technologies Used

- Language: C++  
- Compiler: G++  
- Platform: Linux / Unix

## ▶️ How It Works

- Uses C++ templates for generic programming  
- Each data structure is implemented as a class  
- Supports dynamic memory allocation  
- Provides functions for insertion, deletion, and display

## 📋 Features

- Generic (template-based) implementation  
- Multiple data structures in one library  
- Reusable and modular code  
- Dynamic memory management
